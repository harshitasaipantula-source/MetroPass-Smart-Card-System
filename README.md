# MetroPass – Smart Card Fare and Recharge System

## Project Description
MetroPass is a Java-based application designed to manage metro smart cards, calculate travel fares, recharge card balances, and maintain passenger records. It provides separate Admin and Passenger menus to perform different operations.

## Features
- Register Regular, Student, and Senior Citizen cards
- Calculate metro fares based on stations travelled
- Apply concessions for Student and Senior Citizen cards
- Recharge smart cards
- Check card balance and travel history
- Search, display, and delete card records
- Save and load card records using file handling
- Handle errors using custom exceptions

## Technologies Used
- Java
- Object-Oriented Programming
- File Handling
- Collections (ArrayList)
- Exception Handling

## Concepts Implemented
- Classes and Objects
- Inheritance
- Method Overloading
- Method Overriding
- Abstraction
- Interfaces
- Static members
- User-defined exceptions

## How to Run
1. Download or clone this repository.
2. Open the project in Eclipse.
3. Run `MetroPass.java`.
4. Use the menu options to access Admin or Passenger operations.
